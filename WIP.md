# PRC Newsletter Builder

## Overview

The PRC Newsletter Builder is a WordPress plugin that allows users to create and manage newsletters.

## Dev Plan

### 1. Create a new post type for newsletters

### 2. Create a new taxonomy for newsletter products *lets call this "Newsletters" on the frontend labels* (The Daily Brief, Notifications, Mikes Corner, etc...)

### 3. Create php functionality to convert blocks to MailChimp compatible markup.

### 4. Create php functionality to send newsletter to MailChimp via API.

### 5. Create blocks and or block patterns/bindings for diplaying typical MailChimp things like the unsubscribe link, and mandatory footer text.

### 6. Create a new page template for the newsletter single and newsletters archive and the newsletter product category archive.
